# VA Shopping App — Design System

shadcn/ui primitives restyled to the VA cr-booking workspace: a **dense,
factual, keyboard-fast** internal tool for travel advisors. Not a consumer
marketing site — no gradients, no rounded photography, no motion.

These components are the standard shadcn/ui files under `src/components/ui/`,
re-skinned to the DS token layer in `src/index.css`. Import them exactly as you
would in any shadcn project (`@vas/ui/components/button`, etc.).

## Type

Open Sans throughout — Regular 400, SemiBold 600, Bold 700. The working range is
tight: 11–14px, with 12px doing most of the work. Bold uppercase 11px carries
every eyebrow and column header.

## Geometry & borders

- **Radius:** 4px is the default (buttons, fields, cards). 2px for chips and
  checkboxes. Pill for badges, toggles and slider tracks. 12px only on the modal.
- **Borders are inset rings** — every border is an inset `box-shadow`, so a
  control never shifts size between default / hover / focus / error. 1px neutral
  default, 2px fjord focus, 1px crimson error.
- **Focus** is a 2px fjord ring drawn 2px *outside* the control.
- **Motion is disabled** system-wide. The only animation is the loading spinner.
